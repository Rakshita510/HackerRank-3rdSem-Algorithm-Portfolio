## About This Portfolio

This repository contains my algorithm solutions completed as part of my 3rd Semester coding portfolio. The solutions demonstrate array processing, searching, sorting, greedy problem solving, and basic algorithmic thinking.

## Completed Challenges

| No. | Challenge | Approach | Time Complexity | Auxiliary Space |
|---|---|---|---|---|
| 1 | Mini-Max Sum | Find total sum, minimum and maximum values in one pass | O(n) | O(1) |
| 2 | Birthday Cake Candles | Find the maximum height and count its occurrences | O(n) | O(1) |
| 3 | Insertion Sort – Part 1 | Shift larger elements and insert the last element | O(n) | O(1) |
| 4 | Binary Search | Repeatedly divide the sorted search range into halves | O(log n) | O(1) |
| 5 | Mark and Toys | Sort prices and buy the maximum number within the budget | O(n log n) | O(1) |

## Solutions

### 01 - Mini-Max Sum

Calculates the minimum and maximum sums possible by excluding one element from the array.

### 02 - Birthday Cake Candles

Finds the tallest candle and counts how many candles have that maximum height.

### 03 - Insertion Sort – Part 1

Moves elements larger than the last element to the right and inserts the element into its correct position.

### 04 - Binary Search

Searches for a target value in a sorted array by repeatedly dividing the search range into two halves.

### 05 - Mark and Toys

Sorts the toy prices and purchases the maximum number of toys possible within the given budget.
